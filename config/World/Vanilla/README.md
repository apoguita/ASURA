# The Vanilla pack

The faithful base-game content target: maps, spawn points and doorways, with NPCs, quests and
scripts planned as those features are implemented. This name does not certify content parity.

See [World pack files](../README.md) for selection, layout and current readers, and
[Game packs](../../../docs/guidance/game-packs.md) for the self-contained profile model.

The database catalogue was migrated into map files without overwriting the owner's existing
map edits or restoring deliberately removed spawn files. Unestablished folder placements
remain unplaced; migration did not establish their campaign or region.

Editing this folder edits the base pack. Create a custom copy under another name in
`config/World/` to keep the base pack separate.
